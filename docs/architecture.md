# Архитектура комплекса TruckDiag

TruckDiag — полнофункциональная диагностическая система для тяжёлого коммерческого транспорта (с первоначальным фокусом на семейство грузовиков Scania 2019–2023 Euro 6 и перспективой расширения на Volvo FH 2014+).

Комплекс построен по трёхуровневой архитектуре:
1. **Диагностический Android-клиент** (Jetpack Compose, MVVM, Material 3, Retrofit, WebSocket).
2. **Диагностический сервер / API** (Python, FastAPI, SQLAlchemy 2.0 Async, Alembic, SQLite/PostgreSQL).
3. **Физико-протокольный симулятор грузовика** (SAE J1939, CAN 2.0B 29-bit, генерация PGN/SPN, инъекция DTC).

## 2. Модуль симуляции (TruckSimulator)

Симулятор работает независимо от Android-клиента и эмулирует реальные физические процессы тягача:
- **Состояния ДВС (`EngineState`)**:
  - `ENGINE_OFF`: Двигатель заглушен (0 RPM, 0 км/ч, давление масла 0 бар, напряжение АКБ 24.2 В).
  - `IDLE`: Холостой ход (плавный прогрев до 85 °C, стабилизация на 600 RPM, зарядка АКБ 28.3 В, подкачка ресиверов до 10.5 бар).
  - `DRIVING`: Разгон до крейсерской скорости (~78 км/ч), 12-ступенчатая коробка Opticruise, расчёт оборотов по передаточному числу, динамический наддув и нагрузка.
  - `STOPPING`: Плавное торможение, сброс передач, расход воздуха рабочими тормозами (падение давления в контуре 1).
- **Инъекция неисправностей**:
  - `COOLANT_OVERHEAT`: Перегрев охлаждающей жидкости (>105 °C, код SPN 110 FMI 0).
  - `LOW_OIL_PRESSURE`: Критически низкое давление масла (<1.0 бар, код SPN 100 FMI 1).
  - `LOW_AIR_PRESSURE`: Падение давления в пневматическом контуре 1 (<6.0 бар, код SPN 117 FMI 1).
  - `SCR_NOX_EXCEEDANCE`: Превышение норм токсичности NOx (SPN 4094 FMI 18).

Все синтетические значения и генерируемые кадры маркируются флагом `simulated=true`.

## 3. Готовность к аппаратному адаптеру

Архитектура разделена на абстрактные слои:
- Интерфейс `CanFrame` не привязан к симулятору и напрямую совместим с `SocketCAN` (Linux) и `RP1210` / `PassThru` (Windows).
- Декодер `decode_j1939_frame(can_id, payload)` принимает "сырые" байты и 29-битный ID, поэтому подключение физического адаптера потребует лишь реализации драйвера источника данных без изменения Android UI и REST API.
