# Руководство по протоколу SAE J1939 в TruckDiag

## 1. Структура 29-битного CAN Identifier (Extended CAN 2.0B)

В протоколе SAE J1939 29-битный идентификатор кадра разбивается на функциональные поля:

| Биты | Размер | Обозначение | Описание |
|---|---|---|---|
| **28–26** | 3 бита | **Priority (P)** | Приоритет сообщения (от 0 — наивысший, до 7 — наинизший). Типичные: 3 (управление) или 6 (телеметрия). |
| **25** | 1 бит | **Reserved (R)** | Зарезервирован SAE (обычно 0). |
| **24** | 1 бит | **Data Page (DP)** | Страница данных (0 или 1). |
| **23–16** | 8 бит | **PDU Format (PF)** | Определяет формат передачи и тип адресации (PDU1 или PDU2). |
| **15–8** | 8 бит | **PDU Specific (PS)** | В зависимости от PF: Destination Address (DA) или Group Extension (GE). |
| **7–0** | 8 бит | **Source Address (SA)** | Физический адрес источника (ECU, отправивший кадр). |

### Правило вычисления Parameter Group Number (PGN):
- Если **PF < 240 (0xF0)** (формат **PDU1**, адресное сообщение):
  $$\text{PGN} = (\text{DP} \ll 16) \mid (\text{PF} \ll 8)$$
  В поле PS содержится адрес назначения (**Destination Address, DA**).
- Если **PF \ge 240 (0xF0)** (формат **PDU2**, широковещательное сообщение):
  $$\text{PGN} = (\text{DP} \ll 16) \mid (\text{PF} \ll 8) \mid \text{PS}$$
  Сообщение рассылается всем узлам шины (**Global Broadcast, DA = 0xFF**).

## 2. Реализованные проверенные PGN и SPN

### PGN 61444 (0x00F004) — Electronic Engine Controller 1 (EEC1)
- **Приоритет по умолчанию**: 3
- **Периодичность передачи**: 20 мс / 50 мс
- **Source Address**: 0x00 (Engine #1 / Scania EMS)
- **SPN 513**: *Actual Engine - Percent Torque*
  - Байт 2
  - Разрешение: 1.0 %/бит, смещение: -125.0 % (диапазон: -125 % ... +125 %)
- **SPN 190**: *Engine Speed*
  - Байты 3–4 (Little-Endian, младший байт первым)
  - Разрешение: 0.125 RPM/бит, смещение: 0 (диапазон: 0 ... 8031.875 RPM)
  - *Пример*: сырое значение `0x2000` (8192) $\rightarrow 8192 \times 0.125 = 1024.0$ RPM.

### PGN 61443 (0x00F003) — Electronic Engine Controller 2 (EEC2)
- **Приоритет**: 3
- **Source Address**: 0x00
- **SPN 92**: *Engine Percent Load At Current Speed*
  - Байт 3
  - Разрешение: 1.0 %/бит (диапазон: 0 ... 250 %)

### PGN 65262 (0x00FEEE) — Engine Temperature 1 (ET1)
- **Приоритет**: 6
- **Периодичность**: 1000 мс
- **SPN 110**: *Engine Coolant Temperature*
  - Байт 1
  - Разрешение: 1.0 °C/бит, смещение: -40.0 °C (диапазон: -40 ... +210 °C)
  - *Пример*: сырое значение `0x7D` (125) $\rightarrow 125 - 40 = 85.0$ °C.

### PGN 65265 (0x00FEF1) — Cruise Control/Vehicle Speed 1 (CCVS1)
- **Приоритет**: 6
- **Source Address**: 0x21 (Scania Coordinator COO8) или 0x00
- **SPN 84**: *Wheel-Based Vehicle Speed*
  - Байты 2–3 (Little-Endian)
  - Разрешение: 1/256 км/ч = 0.00390625 км/ч/бит (диапазон: 0 ... 250.996 км/ч)
  - *Пример*: сырое значение `0x5000` (20480) $\rightarrow 20480 / 256 = 80.0$ км/ч.

### PGN 65271 (0x00FEF7) — Vehicle Electrical Power 1 (VEP1)
- **Приоритет**: 6
- **SPN 168**: *Battery Potential / System Voltage*
  - Байты 7–8 (Little-Endian)
  - Разрешение: 0.05 В/бит, смещение: 0 (диапазон: 0 ... 3212.75 В)
  - *Пример*: сырое значение `566` $\rightarrow 566 \times 0.05 = 28.30$ В.

### PGN 61445 (0x00F005) — Electronic Transmission Controller 2 (ETC2)
- **Приоритет**: 3
- **Source Address**: 0x03 (Transmission / Scania Opticruise)
- **SPN 523**: *Transmission Current Gear*
  - Байт 4
  - Разрешение: 1 gear/бит, смещение: -125 (0 = нейтраль, 1..14 = передачи вперёд, отрицательные = задний ход).

### PGN 65274 (0x00FEFA) — Air Supply Pressure (AIR1)
- **Приоритет**: 6
- **Source Address**: 0x0B (Brakes / Scania APS)
- **SPN 117**: *Brake Application / Circuit 1 Air Pressure*
  - Байт 2
  - Разрешение: 8 кПа/бит = 0.08 бар/бит (диапазон: 0 ... 20.0 бар).

### PGN 65263 (0x00FEE7) — Engine Fluid Level/Pressure 1 (EFL/P1)
- **Приоритет**: 6
- **SPN 100**: *Engine Oil Pressure*
  - Байт 4
  - Разрешение: 4 кПа/бит = 0.04 бар/бит (диапазон: 0 ... 10.0 бар).

### PGN 65226 (0x00FECA) — Active Diagnostic Trouble Codes (DM1)
- **Приоритет**: 6
- Структура пакета неисправности:
  - Байты 1–2: состояние контрольных ламп (MIL, Red Stop, Amber Warning, Protect Lamp).
  - Байты 3–6: пакет кода неисправности:
    - **SPN** (19 бит): Байт 3, Байт 4, старшие 3 бита Байта 5.
    - **FMI** (5 бит): младшие 5 бит Байта 5 (Failure Mode Identifier: 0 — выше нормы, 1 — ниже нормы, 3 — замыкание на плюс, 4 — замыкание на массу, и т.д.).
    - **CM** (1 бит): Conversion Method (Байт 6, бит 7).
    - **OC** (7 бит): Occurrence Count (счётчик возникновения ошибки, Байт 6, биты 0–6).

## 3. Разграничение: Общий J1939 vs Данные Scania OEM

1. **SAE J1939 Standard**:
   Описанные выше PGN/SPN строго соответствуют открытому промышленному стандарту SAE J1939. Они едины для тягачей Scania, Volvo, MAN, DAF, Mercedes-Benz и строительной техники.
2. **Scania Proprietary Diagnostics**:
   Глубокая инженерная диагностика Scania (прошивка блоков, адаптация сцепления Opticruise, сброс картриджа осушителя APS, калибровка датчиков подвески ELC, привязка ключей иммобилайзера) использует проприетарные диагностические сессии KWP2000 / UDS по PDU1 PGN 0xEF00 или 0xDA00 с OEM-ключами авторизации Scania SDP3.
   
> **ВАЖНОЕ ОГРАНИЧЕНИЕ БЕЗОПАСНОСТИ**:
> Приложение TruckDiag в текущем MVP работает в безопасном режиме чтения и симуляции (**Read-Only Simulation**). Команды очистки реальных заводских кодов ошибок и запись параметров в физические ECU заблокированы.
