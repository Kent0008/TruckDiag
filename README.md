# TruckDiag — Android-приложение для диагностики грузовых автомобилей

**TruckDiag** — это современный диагностический комплекс для коммерческого транспорта (Scania R/S 2019–2023 Euro 6, Volvo FH 2014+) с собственным REST & WebSocket API, физико-протокольным симулятором грузовика и поддержкой стандарта **SAE J1939**.

---

## 1. Возможности комплекса

- **Собственный REST & WebSocket API** на FastAPI с базой данных SQLite/PostgreSQL и автогенерацией Swagger UI (`/docs`).
- **Реалистичный симулятор грузовика**:
  - Физическая динамика: плавное изменение оборотов ДВС, скорости, температуры ОЖ, давления масла и воздуха в пневмоконтурах тормозов.
  - 4 режима работы: `ENGINE_OFF` (заглушен), `IDLE` (холостой ход), `DRIVING` (разгон, 12-ступенчатая Opticruise), `STOPPING` (торможение).
  - Инъекция тестовых неисправностей (перегрев ДВС, падение давления масла/воздуха, система нейтрализации AdBlue NOx).
- **Протокол SAE J1939 / CAN 2.0B (29-бит)**:
  - Генерация и разбор реальных кадров шины CAN: Priority, Data Page, PDU Format, PDU Specific, PGN, Source Address, DLC, Payload.
  - Точное побитовое декодирование стандартных SPN (Обороты ДВС SPN 190, Температура ОЖ SPN 110, Скорость SPN 84, Напряжение АКБ SPN 168, Давление масла SPN 100, Давление в тормозном контуре SPN 117, Топливо SPN 96).
  - Чтение диагностических кодов DM1 (Active Diagnostic Trouble Codes) с вычислением SPN, FMI и Occurrence Count.
  - Разделение открытого J1939 и OEM-данных Scania.
- **Android-клиент (Jetpack Compose, Material 3, Dark Automotive Theme)**:
  - **Главная**: состояние сервера, активный сеанс, выбранный тягач, быстрый запуск демо.
  - **Связь**: настройка адреса API, пресеты для эмулятора и локальной сети Wi-Fi, пинг сервера.
  - **Live Data**: карточки телеметрии в реальном времени, переключатель режимов ДВС, фильтрация по категориям (ДВС, КПП, Тормоза, Электрика).
  - **DTC Коды**: сканирование виртуальных блоков (EMS, COO8, GMS, EBS), уровни критичности (`CRITICAL`, `WARNING`, `INFO`), возможные причины.
  - **CAN Шина**: "живой" поток 29-битных кадров шины CAN.
  - **Декодер**: интерактивная форма ввода произвольного CAN ID и Payload в формате HEX с расшифровкой в инженерные величины.
  - **Сеансы**: создание и управление диагностическими сессиями.
  - **Отчёты**: формирование и экспорт диагностических отчётов в JSON.
  - **Настройки**: информация о версиях, режимах работы и протоколах.

> **ВАЖНОЕ ПРИМЕЧАНИЕ О ДЕМОДАННЫХ**:  
> На текущем этапе физический адаптер отсутствует. Все телеметрические параметры, кадры CAN и диагностические коды генерируются встроенным симулятором тягача и явно маркируются плашкой **SIMULATED / DEMO**. Очистка кодов реальных ECU отключена в целях безопасности.

## 3. Быстрый запуск на Windows 10/11

### Требования:
1. **Python**: версия 3.10, 3.11, 3.12 или выше.
   - Проверка: откройте командную строку (`cmd`) и введите `python --version`.
   - Если Python не установлен, скачайте его с [python.org](https://www.python.org/downloads/) (обязательно отметьте галочку **"Add Python to PATH"** при установке).
2. **Android Studio** (или Java JDK 17+ и Android SDK) — требуется только для запуска Android-клиента.

---

### Шаг 1. Запуск Backend и симулятора

Для запуска сервера просто запустите файл:
```cmd
scripts\start-backend.bat
```
Скрипт автоматически:
1. Создаст виртуальное окружение в папке `backend\venv` (если его ещё нет).
2. Установит все необходимые зависимости из `requirements.txt`.
3. Запустит сервер FastAPI на `http://0.0.0.0:8000`.

После запуска откройте в браузере:
- **Интерактивная документация (Swagger UI)**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **Проверка работоспособности**: [http://localhost:8000/api/v1/health](http://localhost:8000/api/v1/health)

### Остановка сервера:
Для остановки сервера дважды щёлкните:
```cmd
scripts\stop-backend.bat
```

### Запуск тестов backend:
```cmd
scripts\run-tests.bat
```
*(Все 18 тестов выполняются автоматически и проверяют эндпоинты, математику J1939, валидацию CAN ID и генерацию отчётов).*

## 4. Сборка и запуск Android-клиента

### Способ А: Сборка готового APK через Gradle Wrapper (без открытия Android Studio)
В папке репозитория выполните команду:
```cmd
cd android
gradlew.bat assembleDebug
```
Собранный установочный файл APK появится по адресу:
```
android\app\build\outputs\apk\debug\app-debug.apk
```
Вы можете скопировать этот файл на телефон или перетащить мышкой в окно Android Emulator.

### Способ Б: Запуск через Android Studio
1. Запустите Android Studio.
2. Выберите **Open** и укажите папку `D:\TruckDiag\android`.
3. Дождитесь автоматической синхронизации Gradle.
4. Выберите виртуальное устройство (эмулятор) или подключённый по USB смартфон и нажмите зелёную кнопку **Run (Shift+F10)**.

## 5. Подключение Android-приложения к API

### Вариант 1: Запуск на эмуляторе Android Studio
1. В приложении перейдите на экран **"Связь"** (иконка сетевого разъёма в верхнем правом углу экрана "Главная").
2. Нажмите кнопку быстрого шаблона:
   ```
   10.0.2.2 (Эмулятор)
   ```
   *(Адрес `10.0.2.2` — это стандартный сетевой мост Android Emulator, указывающий на ваш компьютер).*
3. Нажмите **"Проверить связь с сервером"**. Появится зелёная плашка подтверждения связи.

### Вариант 2: Запуск на физическом Android-телефоне по Wi-Fi
1. Убедитесь, что ваш компьютер и телефон подключены к **одной и той же Wi-Fi сети**.
2. Узнайте локальный IP-адрес вашего компьютера:
   - Нажмите `Win + R`, введите `cmd` и нажмите Enter.
   - Выполните команду `ipconfig`.
   - Найдите строку **IPv4-адрес** (обычно `192.168.0.XXX` или `192.168.1.XXX`).
3. В приложении TruckDiag на телефоне откройте экран **"Связь"** и введите:
   ```
   http://IP_ВАШЕГО_КОМПЬЮТЕРА:8000
   ```
   *(например: `http://192.168.1.55:8000`).*
4. Нажмите **"Проверить связь с сервером"**.

## 6. Опциональный запуск через Docker Compose (с PostgreSQL)

Если на компьютере установлен Docker Desktop, вы можете запустить комплекс в контейнерах:
```cmd
docker-compose up -d
```
Это поднимет:
- Базу данных PostgreSQL 16 на порту 5432.
- Сервер TruckDiag API на порту 8000.

Для остановки:
```cmd
docker-compose down
```
